Each assignment explores different modern web development frameworks and technologies, ranging from server-side scripting (PHP, Servlets, Spring Boot) to modern frontend libraries (React).

## List of Practicals

### [Assignment 1: Electricity Bill Calculator (PHP)](./Assignment%201)
**Description:** A responsive website to calculate electricity bills using **PHP**, HTML, Bootstrap, and jQuery.
**Conditions:**
- First 50 units: Rs. 3.50/unit
- Next 100 units: Rs. 4.00/unit 
- Next 100 units: Rs. 5.20/unit
- Above 250 units: Rs. 6.50/unit

### [Assignment 2: Real-Time World Clock Dashboard (React)](./Assignment%202)
**Description:** An advanced real-time clock dashboard application built using **React**. It combines an Analog Clock, Digital Clock, Time zone Management, Alarm Features, and Dynamic UI Controls into a single responsive system. Simulates a professional world-clock dashboard with live time updates across multiple regions.

### [Assignment 3: Electricity Bill Calculator (Servlet & JSP)](./Assignment%203)
**Description:** A Java-based responsive website to calculate electricity bills using **Java Servlets and JSP**. Uses the same billing conditions as Assignment 1.
**Conditions:** Same as Assignment 1.

### [Assignment 4: VIT Student Result Portal (React)](./Assignment%204)
**Description:** A responsive website to prepare and display one semester's result for VIT students using **React**. It calculates the final grades across four subjects based on a weighted system:
- MSE Marks: 30% weightage
- ESE Marks: 70% weightage

### [Assignment 5: VIT Student Result Portal (Spring Boot)](./Assignment%205)
**Description:** A full-stack responsive website to prepare one semester's result for VIT students using **JavaScript**, **Spring Boot**, and **MySQL/MongoDB**. Uses the same 30% MSE / 70% ESE weighting system as Assignment 4.

## Getting Started

To run any of the assignments locally, navigate to the specific assignment folder and follow the instructions provided in its respective `README.md` (or simply run the appropriate server). 

### Prerequisites
- **PHP/Apache Server** (e.g., XAMPP/WAMP) for Assignment 1.
- **Node.js & npm** for React projects (Assignments 2 & 4).
- **Java JDK 17+ & Tomcat Server** for Assignment 3.
- **Java JDK & Maven** for Spring Boot (Assignment 5).
