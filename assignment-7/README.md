# Assignment 7 - Online Book Store (Spring Boot & React)

## Description
A full-stack, responsive website for an online bookstore using **Spring Boot (Java)** for the backend REST APIs and **React.js** for the frontend. The application includes four main pages: Home Page, Login Page, Registration Page (with secure authentication), and a Catalogue Page with search and filtering capabilities.

## Tech Stack
- **Backend**: Spring Boot, Java, Spring Security, Spring Data JPA, MySQL
- **Frontend**: React.js, React Router, Framer Motion
- **Build Tools**: Gradle (Backend), Vite (Frontend)
